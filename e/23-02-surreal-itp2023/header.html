This is the accompanying material for the paper:

  • Formalizing the Conway Normal Form of Surreal Numbers (short paper)

by Karol Pąk and Cezary Kaliszyk submitted to ITP 2023

The formalization is compatible with the latest (stable) Mizar windows version 8.1.11 5.68.1412, and the latest Mizar windows version 8.1.12 5.73.1435

In order to recheck the formalization:

  • Unpack Mizar into c:\mizar
  • Run: 
    install c:\mizar
  • Put the formalization directories text and dict [.tgz] in c:\mizar
  • Build a local library 
    miz2prel text\surrealo
miz2prel text\surrealr
miz2prel text\surreali
miz2prel text\surrealn
    or add the content of formalization directories prel in c:\mizar\prel
  • Run the verifier: 
    mizf text\surrealo
mizf text\surrealr
mizf text\surreali
mizf text\surrealn
mizf text\surrealc
  • The above step already verified the proofs, but to additionally obtain the more readable abstracts run: 
    miz2abs text\surrealo
miz2abs text\surrealr
miz2abs text\surreali
miz2abs text\surrealn
miz2abs text\surrealc
    or add the content of formalization directories abstr
