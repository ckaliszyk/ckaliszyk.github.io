In order to recheck the formalization under Windows:

  • Unpack Mizar into c:\mizar
  • Run: 
    install c:\mizar
  • Put the formalization directories text and dict [.tgz] in c:\mizar
  • Build a local library 
    miz2prel text\surreali
miz2prel text\surreals
miz2prel text\surrealn
miz2prel text\surrealc
    or add the content of formalization directories prel in c:\mizar\prel
  • Run the verifier: 
    mizf text\surreal0
mizf text\surrealo
mizf text\surrealr
mizf text\surreali
mizf text\surreals
mizf text\surrealn
mizf text\surrealc
  • The above step already verified the proofs, but to additionally obtain the more readable abstracts run: 
    miz2abs text\surreal0
miz2abs text\surrealo
miz2abs text\surrealr
miz2abs text\surreali
miz2abs text\surreals
miz2abs text\surrealn
miz2abs text\surrealc
    or add the content of formalization directories abstr

For other systems (e.g. Linux):

  • Make sure Mizar is installed, in the path and the MIZFILES environment variable is set according to the message at the end of installation
  • Add the supplementary dicts_extra 
      mv dicts_extra/* dicts
  • Run: 
      for i in 0 o r i n s c; do mizf text/surreal${i}.miz; miz2prel text/surreal${i}.miz; done
