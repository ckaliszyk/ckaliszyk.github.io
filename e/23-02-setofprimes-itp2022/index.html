This is the accompanying material for the paper:

  • Formalizing the set of primes as an alternative to the DPRM theorem (short paper)

by K.Pąk and C.Kaliszyk submitted to ITP 2022

The formalization is compatible with the latest Mizar windows version 8.1.11 5.68.1412

In order to recheck the formalization:

  • Unpack Mizar into c:\mizar
  • Run: 
    install c:\mizar
  • Put the formalization directories text and dict in c:\mizar
  • Run the verifier: 
    mizf text\hilb10_7
mizf text\hilb10_8
miz2prel text\hilb10_7
mizf text\polynom
  • The above step already verified the proofs, but to additionally obtain the more readable abstracts run: 
    miz2abs text\hilb10_7
miz2abs text\hilb10_8
miz2abs text\polynom
The package "pack2" includes improvements to the formalization based on the reviewer comments. pack2.tgz
