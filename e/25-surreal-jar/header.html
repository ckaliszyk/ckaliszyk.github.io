In order to recheck the formalization under Windows:

  • Unpack Mizar into c:\mizar
  • Run: 
    install c:\mizar
  • Put the formalization directories text and dict [.tgz] in c:\mizar
  • Remove the original surrealc.* files from prel\s 
    c:\mizar\prel\s\surrealc.dcl
c:\mizar\prel\s\surrealc.dco
c:\mizar\prel\s\surrealc.def
c:\mizar\prel\s\surrealc.dfr
c:\mizar\prel\s\surrealc.dno
c:\mizar\prel\s\surrealc.sch
c:\mizar\prel\s\surrealc.the
  • Build a local library 
    miz2prel text\surrealc
miz2prel text\surreac1
    or replace the above files prel\s\surreal*.* with those from the prel folder in [.tgz]
  • Run the verifier: 
    mizf mml\surreal0
mizf mml\surrealo
mizf mml\surrealr
mizf mml\surreali
mizf mml\surreals
mizf mml\surrealn
mizf text\surrealc
mizf text\surreac1
  • The above step already verified the proofs, but to additionally obtain the more readable abstracts run: 
    miz2abs text\surrealc
miz2abs text\surreac1
    the modified surrealc.abs file and the remaining surreac1.abs file are now available in the text directory.

For other systems (e.g. Linux):

  • Make sure Mizar is installed, in the path and the MIZFILES environment variable is set according to the message at the end of installation
  • Remove the non-generalized CNF from the distribution: 
    rm /usr/local/share/mizar/prel/s/surrealc.*
  • In the formalization directory run: 
    mizf text/surrealc.miz
miz2prel text/surrealc.miz
mizf text/surreac1.miz
miz2prel text/surreac1.miz
